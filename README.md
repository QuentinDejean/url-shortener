# url-shortener

URL shortener built on the [ts-service-starter](https://github.com/QuentinDejean/ts-service-starter) boilerplate: Fastify, Zod, Postgres (Drizzle ORM on `pg`, drizzle-kit migrations), Vitest, Biome, pino.

## Quickstart

```bash
pnpm i
cp .env.example .env
docker compose up -d     # Postgres 16 on :5432
pnpm migrate             # applies pending migrations in migrations/
pnpm dev                 # http://localhost:3000/health
pnpm test
```

Other: `pnpm db:generate` (create a migration from `src/db/schema.ts`), `pnpm check` (Biome), `pnpm typecheck`, `pnpm build`.

## Layout

- `src/server.ts` app setup · `src/index.ts` entrypoint · `src/config.ts` env validation
- `src/routes/` one file per resource · `src/db/` Drizzle client, schema, migration runner · `src/lib/` pure logic
- `migrations/` forward-only SQL files generated by drizzle-kit (tracked in `drizzle.__drizzle_migrations`)

See `AGENTS.md` for conventions the coding agent follows.
